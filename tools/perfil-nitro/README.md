# Perfil do Discord com Nitro (descrições do Nitro)

`perfil.py` troca o mock "Seu perfil com Nitro" do "Como utilizar" por um perfil fiel ao popout do Discord com Nitro
(tema de perfil, banner animado, decoração de avatar, status, balão de status, insígnias, nome com estilo do Nitro).

Variações que usam: Conta Nitrada 1 Mês (`var_FSlNGUlGqE1`), Conta Nitrada 3 Meses (`var_3LUTGFaDpwO`),
Código Nitro 1 Mês + Ativação (`var_AfmTPTQa0sU`), Código Nitro 3 Meses + Ativação (`var_DsbVHeWxSSE`).

`originais/` guarda as descrições de antes (21/11/2026). Para voltar, envie o arquivo com
`PATCH https://api.ereemby.app/api/v2/variants/<id>` e o corpo `{"description": "<conteúdo do arquivo>"}`.
